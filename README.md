

# app-volei
Implementation of a system for management of volley matches.

# Setup for the project
🟢 Install all dependencies
```
npm install
```

# Enable local server
🟢 Run server
```
node server.js
```
🟢 Service works at port 3000 by default
```
http://localhost:3000
```

# Unit tests for services 
🟢 Run domain exception tests from the rules of the business (39 should pass)
🔴 There are incomplete domain tests to be done
🔴 There are not tests for HTTP exceptions yet
```
npm test
```

# Documentation of Swagger (ongoing)
🟢 Access all groups of routes within this app
🔴 Not all routes are entirely documented, they will be done later time
```
http://localhost:3000/api-docs
```
