

# app-volei
Implementation of a system for management of volley matches.

# Run project
🟢 Install all dependencies
```
npm install
```

# Enable local server
🟢 Run server
```
node server.js
```
🟢 Service works at port 3000 by default
```
http://localhost:3000
```

# Testar serviços 
🟢 Run tests of exceptions from the rules of the business (39 should pass)
```
npm test
```
